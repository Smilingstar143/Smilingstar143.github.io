CG PART-B LAB PROGRAMS

1) Create and Edit Images Using GIMP

Steps:

  1. Open GIMP software.
  2. Click File → New and create a new image with size 1280 × 720.
  3. Choose a suitable background colour.
  4. Open an image using File → Open.
  5. Use the Pencil Tool to draw or edit the image.
  6. Use Rectangle Select Tool to select an area.
  7. Use Brush Tool to fill colours.
  8. Use Text Tool to add text to the image.
  9. Adjust the text size, font and colour.
  10. Save the project as XCF and export it as program1.png.

2) Image Enhancement Using GIMP

Steps:

  1. Open GIMP software.
  2. Click File → Open and select a photograph.
  3. Choose the Crop Tool to crop the image.
  4. Click Image → Scale Image and set width to 800 pixels.
  5. Maintain the linked proportions.
  6. Click Colors → Brightness-Contrast.
  7. Adjust brightness and contrast as required.
  8. Click OK to apply the changes.
  9. Save the project and export it as enhanced_photo.jpg.

3) Create Poster/Banner Using GIMP

Steps:

  1. Open GIMP software.
  2. Click File → New and create an image of size 1080 × 1350.
  3. Choose a suitable background colour or gradient.
  4. Open the required images.
  5. Scale and move the images into position.
  6. Use the Text Tool to add event name, date, time and venue.
  7. Use the Brush Tool for decoration.
  8. Add borders and shapes using the Rectangle Tool.
  9. Save the project as XCF.
  10. Export the poster as JPG or PNG.

5) Perform Audio Operations Using Audacity

Steps:

  1. Open Audacity software.
  2. Click File → Import → Audio and select an audio file.
  3. Select the required portion of the audio.
  4. Use Noise Reduction to reduce background noise.
  5. Use the Trim option to remove unwanted portions.
  6. Import another audio file if required.
  7. Arrange and mix the audio tracks.
  8. Adjust the volume of each track.
  9. Apply suitable audio effects.
  10. Play and check the final audio.
  11. Save the project and export it as WAV or MP3.

6) Create a Short Audio Clip with Background Music and Noise-Free Narration

1. Prepare Project

  1. Open Audacity.
  2. Connect microphone and select Mono.
  3. Import background music.

2. Record Narration

  1. Click below the music track.
  2. Press Record and speak.
  3. Press Stop.

3. Remove Noise

  1. Select 3 seconds of silence.
  2. Click Noise Reduction → Get Noise Profile.
  3. Select full narration and click OK.

4. Trim and Align

  1. Delete unwanted parts.
  2. Adjust voice after music intro.
  3. Remove extra music.

5. Balance Sound

  1. Reduce music volume.
  2. Check both tracks.
  3. Apply Fade Out.

6. Save and Export

  1. Mix all tracks.
  2. Save the project.
  3. Export as MP3 or WAV.

7) Create and Edit a Video Using OpenShot

Steps:

  1. Open OpenShot Video Editor.
  2. Click File → Import Files and add pictures.
  3. Drag the pictures onto Track 1 in the timeline.
  4. Adjust each picture to about 3–4 seconds.
  5. Add text using Title.
  6. Add transitions between pictures:
    • Open Transitions.
    • Choose a simple transition such as Fade.
    • Drag it between two clips.
  7. Add background music:
    • Import an MP3 file.
    • Drag it to Track 2.
    • Reduce the volume if necessary.
  8. Preview the video using the Play button.
  9. Click Export Project → Export Video.
  10. Select MP4 and click Export Video.

8) Create Short Video Presentation/Advertisement Using OpenShot

Steps:

  1. Open OpenShot Video Editor.
  2. Import nature video clips.
  3. Drag the clips onto Track 1.
  4. Trim each clip to about 5–8 seconds.
  5. Arrange the clips in the required order.
  6. Add Fade transitions between clips.
  7. Add a title using the Title option.
  8. Import background music and drag it to Track 2.
  9. Reduce the music volume if necessary.
  10. Add the final title "Explore Nature".
  11. Preview the complete video.
  12. Export the final video in MP4 format.
