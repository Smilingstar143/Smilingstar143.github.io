CG PART-B Lab Programs

PROGRAM 1: Create and Edit Images Using GIMP

Steps:

  1. Open GIMP software.
  2. Go to File → New and create a new document with width 1280 pixels and height 720 pixels.
  3. Choose the background color and click OK.
  4. Open an image using File → Open.
  5. Select the Pencil Tool and draw on the image.
  6. Use the Rectangle Select Tool to select an area.
  7. Use the Brush Tool to fill the selected area with color.
  8. Select the Text Tool and type the required text.
  9. Adjust the font size, color and position.
  10. Save the project using File → Save as an XCF file.
  11. Export the final image using File → Export As and save it as program1.png.

PROGRAM 2: Image Enhancement Using GIMP

Steps:

  1. Open GIMP software.
  2. Go to File → Open and select the required photograph.
  3. Select the Crop Tool and crop the unwanted areas.
  4. Use Image → Scale Image to resize the photograph.
  5. Enter the width as 800 pixels and keep the proportions linked.
  6. Click Scale to apply the changes.
  7. Go to Colors → Brightness-Contrast.
  8. Adjust brightness and contrast to improve the image.
  9. Click OK to apply the changes.
  10. Save the project and export the enhanced image as enhanced_photo.jpg.

PROGRAM 3: Create a Poster / Banner Using GIMP

Steps:

  1. Open GIMP software.
  2. Go to File → New and create a document with width 1080 pixels and height 1350 pixels.
  3. Choose a suitable background color or apply a gradient.
  4. Open the required images and add them to the poster.
  5. Use the Scale Tool to resize the images.
  6. Use the Move Tool to arrange the images properly.
  7. Select the Text Tool and add the event name, date, time and venue.
  8. Adjust the font style, size and color.
  9. Use the Brush Tool for decoration.
  10. Use the Rectangle Tool to create borders and shapes.
  11. Arrange all elements properly to complete the poster.
  12. Save the project as an XCF file and export it as JPG or PNG.

PROGRAM 5: Perform Audio Operations Using Audacity

Steps:

  1. Open Audacity software.
  2. Import an audio file using File → Import → Audio.
  3. Select a portion of the audio using the Selection Tool.
  4. Use the Noise Reduction option to reduce background noise.
  5. Use the Trim option to remove unwanted portions.
  6. Import another audio file if required.
  7. Arrange and mix the audio tracks.
  8. Adjust the volume levels of the tracks.
  9. Apply suitable sound effects.
  10. Play the audio and check the final output.
  11. Save the project and export the final audio as WAV or MP3.

PROGRAM 6: Create and Edit Video Using OpenShot

Steps:

  1. Open OpenShot Video Editor.
  2. Import pictures using File → Import Files.
  3. Drag the pictures to Track 1 on the timeline.
  4. Set the duration of each picture to 3–4 seconds.
  5. Add a title using Title → Title.
  6. Place the title on the timeline.
  7. Add a Fade transition between the pictures.
  8. Import an MP3 audio file.
  9. Drag the audio file to Track 2.
  10. Preview the video and check the editing.
  11. Export the final video in MP4 format.

PROGRAM 8: Create a Short Video Presentation / Advertisement Using OpenShot

Steps:

  1. Open OpenShot Video Editor.
  2. Import nature video clips into the project.
  3. Drag the clips to Track 1.
  4. Trim each clip to 5–8 seconds.
  5. Arrange the clips in the required order.
  6. Add Fade transitions between the clips.
  7. Add a title using Title → Title.
  8. Import background music and place it on Track 2.
  9. Reduce the background music volume.
  10. Add the final title "Explore Nature".
  11. Preview the complete video.
  12. Export the final video in MP4 format.
